# Manuscript phenotype-prediction figure — scripts 50 and 51

**This figure addresses RIL phenotype reconstruction and prediction, not evolutionary predictability.**

## What these scripts do

**50_Beta_top75_CV_and_K_sensitivity.R** fills the missing `beta` entry in the five-fold, 75-marker GWAS predictive model used in script 16. It uses the exact same RIL folds and fixed composite `beta` phenotype as the existing rrBLUP analysis, verifies their agreement, and ranks/LD-clumps markers only on training RILs. It also evaluates `K = 1, 2, 5, 10, 20, 40, 75, 125, 200` for **beta** to show how predictive performance changes with the number of GWAS markers. This is a sensitivity analysis, not a license to choose the best K from held-out folds.

**51_Phenotype_three_panel_manuscript_figure.R** reads the per-RIL prediction table generated by your existing script 49, integrates the missing held-out beta predictions from script 50 and produces the three-column comparison for four main-text traits (SF, SB, area.F, beta) and all eight traits in the supplement.

- Column 1: full-data, legacy R²=0.2 GWAS significant-marker score, calibrated *in sample* into phenotype units solely for graphical comparability. Statistic: in-sample `r²`. **Not an unbiased estimate of variance explained.**
- Column 2: GWAS markers ranked and LD-clumped **within training folds**, with a fixed maximum of 75 markers and ridge shrinkage tuned using training RILs. Statistic: held-out predictive `R²`.
- Column 3: genome-wide rrBLUP/GBLUP on the same held-out RILs and folds, using 2,112 LD-pruned markers in your previous run. Statistic: held-out predictive `R²`.

All three panels use observed RIL phenotype SD units on the axes; the first panel is based on its original historic adjusted phenotypes and the others on the current adjusted RIL BLUEs, with any differences explicitly checked in `51_Legacy_vs_current_phenotype_QC.csv`. CV predictions are **not** individually rescaled to unit variance, so their shrinkage is retained. No source-population-held-out analysis appears anywhere in these scripts.

## Why 75 markers?

**75 was a manually fixed reporting choice in script 16 (`chosen_K <- 75L`), not a statistically optimized marker count.** Script 16 compared K=1, 2, 5, 10, 20, 40, 75, 125 and 200. Previous held-out results for SF and SB were strongest at K=20, and more markers did not consistently improve predictions. Keeping K=75 makes this new beta panel a direct, *honest held-out* completion of the existing seven-trait comparison, without choosing K after seeing its test-set accuracy.

GBLUP already addresses the "why not use all markers?" question by using approximately 2,112 genome-wide pruned markers with regularization. Simply including every GWAS SNP as an independent fixed effect (especially linked SNPs) is not a suitable unpenalized comparison. The pruned-marker GBLUP is not literally every typed SNP; a full-marker sensitivity run is a separate option.

For a future **optimal sparse predictor** claim, choose K and shrinkage jointly with **nested cross-validation entirely inside each outer training set**. Selecting the best K from the outer-fold performance curves in scripts 16/50 would be optimistic. The current figure therefore calls the sparse comparator *fixed 75-marker GWAS*, never *best GWAS model*.

## Proposed manuscript caption

> **Phenotypic reconstruction and out-of-sample genomic prediction in recombinant inbred lines.** Rows show SF, SB, body area (area.F), and the fixed seven-trait fitness-related index (beta). The left column shows descriptive in-sample genetic scores derived from significant markers in the legacy R²=0.2 GWAS analysis; scores are linearly calibrated against the same RIL phenotypes for display. The middle column shows random-RIL five-fold out-of-fold predictions from at most 75 training-selected, LD-pruned GWAS markers fitted with ridge regression. The right column shows five-fold out-of-fold GBLUP predictions based on genome-wide relatedness. The same held-out RILs and folds were used for the middle and right panels. Points represent RILs; values are standardized in units of the observed phenotype's standard deviation, with the dashed line indicating perfect prediction. Reported r² in the left column is in-sample squared correlation, whereas R² in the middle and right columns is held-out predictive R². These are distinct estimands and should not be directly compared as percentages of variance explained.

**Cautions:** the original in-sample reconstruction uses the legacy LD-cluster set, not the newer R5 clusters. The fitness-related beta index uses the previously fixed selection weights, and this CV design does not re-estimate those weights in each fold. The bootstrap intervals resample RILs within folds and do not account fully for relatedness, or uncertainty in choosing fitness weights.
