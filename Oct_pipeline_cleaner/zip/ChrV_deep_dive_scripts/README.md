# Chromosome V (6–8 Mb) — R5 deep dive (scripts 54–56)

## Scientific purpose

The previous **full 802-cluster** comparison found LOCO predictive R² of approximately **0.0796 for β** and **0.0474 for covariance PC1**. The apparent advantage of β was concentrated in the **12 testable R5 groups** assigned to the 2-Mb block `V_3`; β correctly predicted the calibrated sign in 10/12 versus 2/12 for PC1. These groups are **not independent replicates**: several lie in a linked genomic region. In particular, R5 groups **844** and **858** contain **1,475 and 3,640** GWAS SNPs, respectively. A within-cluster exploratory screen previously marked the lead-SNP pairs involving SF/BS and FB/BS in **group 848** as potentially separable signals, but that screen does not prove multiple causal variants.

**Purpose:** distinguish a predictive β-vs-PC1 discrepancy from distinct genetic signals, LD-mediated effects, and possible shared haplotypes without claiming proof of molecular pleiotropy or epistasis.

## Order of execution

Place these three R scripts in `Oct_pipeline_cleaner/` (or another script folder), and **run from the original project root**, not the script folder:

```r
source('Oct_pipeline_cleaner/54_ChrV_Predictor_dissection.R')
source('Oct_pipeline_cleaner/55_ChrV_RIL_LD_structure.R')
source('Oct_pipeline_cleaner/56_ChrV_PoolSeq_trajectories.R')
```

Each script writes to **`selection_results/chrV_deep_dive/`**. The scripts use base R. Running 55 loads the potentially large RIL genotype matrix; running 56 loads the Pool-seq count matrices. Run sequentially; restart an R session between 55 and 56 if memory is limiting.

### Script 54 — predictive discrepancy and trait-effect decomposition

Needs inputs already generated by scripts 11, 13 and 53:

- `selection_results/drift_oneG0_nullfit/R5/11_Clusters_selection_and_GWAS_09f.csv`
- `selection_results/drift_oneG0_nullfit/R5/multivariate_prediction/13_Gradient_weight_QC.csv`
- `selection_results/beta_vs_PC1/53_Matched_predictions.csv`

Alternative flat filenames in the project root are accepted. Script 45's full table and script 17's trait-pair diagnostics are optional but recommended.

Checks all 802 unique group IDs and GWAS-beta consistency; refits and **verifies the held-out-V** β and PC1 calibrations against script 53 to near machine precision. Produces a twelve-group audit, separate chromosome-V audit, trait-specific β and PC1 contributions, source selection-tag annotations, regional squared-error contributions and PDF figures. The baseline-relative trait contributions sum to the calibrated predicted value *plus an intercept*. It is a descriptive decomposition of statistical predictors, **not a causal mediation analysis**.

Expected QC with the currently supplied files: 802 matched groups, 127 on V, 12 in V_3; absolute differences in reconstructed predictions should be <1e-8. A supplied independent Python cross-check is `54_Independent_Python_reference_V3.csv`. No R execution was performed in preparing this package; this independent reference is a useful validation target.

### Script 55 — RIL LD across the region

Requires the original project files:

- `RData/Preparatory_GLMM_NaCl_only_withBeta.RData` (RIL × SNP `genotype_matrix`)
- `data_BLUE_GridLMM_NaCl/SNP_phase_clusters_R5.csv` **or** the more comprehensive `selection_results/unified_frequency_inclusive_R5/43_All_SNP_phase_slope_and_inclusion_QC.csv`

Uses the GWAS R5 table to consider **all 15 R5 groups** with representative coordinates at V:6–8 Mb, **not just the 12 with eligible evolutionary slopes**. Prioritizes the preselected neutral-test tag, script-17 lead SNPs, named focal sites (including `V_6322080` and `V_6300718` for group 848), nearest-centroid variants, and a spatially spread sample of further markers (default up to 8/group). Reports original R5 member counts, marker sampling, per-pair RIL genotype signed correlation and r², and a tag-LD heat map. The group-boundary summary uses members actually typed in the RIL matrix; not every genomic variant may be present. Sampling a handful of tags **cannot establish absence of linkage**. A descriptive effective dimension is calculated only for selected genotype markers; it is not a count of selected loci.

### Script 56 — per-population exact-SNP evolutionary trajectories

Requires the corrected original project Pool-seq workflow:

- `RData_GridLMM_NaCl/08_PoolSeq_prepared.RData`
- `selection_results/09_Selection_SNP_results.csv`
- `Oct_pipeline_cleaner/09f_drift_functions.R`
- `Oct_pipeline_cleaner/43_Unified_config_and_helpers.R`
- `Oct_pipeline_cleaner/43x_Integrate_rawSYNC_R5_SNPs.R`
- `Oct_pipeline_cleaner/20_GA_population_status.csv`
- `data_BLUE_GridLMM_NaCl/SNP_phase_clusters_R5.csv`
- Strongly recommended: `selection_results/frequency_strata/34a_Focal_raw_SYNC_ALT_counts.csv` for low-frequency SNPs absent from the original filtered count matrix

Reads the **GWAS-ALT-oriented** read counts and checks correspondence with the Pool-seq sample manifest. The older G0 sample `A6G140` is excluded from the analysis; **A00** is the unique baseline. The main evolutionary trajectories use the surviving **GA1, GA2, GA4**; extinct GA3 is plotted separately as a supplement. Files include exact-SNP coverage QC, sample-level ALT and phase-aligned frequencies, descriptive endpoint changes and per-cluster PDF trajectories. It **does not derive new significance tests or select SNPs based on favorable evolutionary responses**.

Important: SNP trajectories and cluster-median evolutionary slopes are different summaries. Do not compare a single tag to the group median as if these were identical measurements.

## What these scripts can, and cannot, establish

**Can:** determine which traits drive the held-out-V β prediction, whether the β–PC1 difference reflects a few groups, whether apparently separate groups show strong RIL LD, whether groups include internally distinct lead SNPs, and whether exact SNPs show consistent or differing trajectories across GA populations.

**Cannot:** by themselves identify the causal locus, prove molecular pleiotropy, show epistasis, distinguish true fitness effects from hitchhiking, or provide independent replication for 12 linked clusters. These are post hoc regional studies chosen after seeing prediction errors; do not present an associated p-value as a prespecified confirmatory test. The underlying whole-genome PC1/β comparison still includes evolutionary calibration from the training chromosomes and is not a zero-evolution-data forecast.
